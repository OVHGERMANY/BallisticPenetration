# BallisticPenetration Field Reports

Field reports are created automatically while the game is running.

If something looks wrong, press `F8`. This marks the moment in the same report; it does not pause the game and no text entry or manual notes are required.

Reports are stored in:

`BepInEx\FieldReports\BallisticPenetration`

After the game closes, send the newest `.bpreport` file.

If the game crashes, a `.partial.bpreport` file is still useful and can be sent directly. The next game start preserves it under a recovered-crash filename.

Reports remain local. BallisticPenetration does not upload them or open a network connection.
