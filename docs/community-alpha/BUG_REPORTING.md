# Bug Reporting

Use the repository's structured issue form that best matches the defect. Search existing issues first and add evidence to an existing report when the behavior is the same.

Every useful report includes:

- mod version, release tag, and exact commit;
- SPT and EFT versions;
- operating system and relevant hardware;
- complete installed-mod list with versions;
- whether the optional telemetry tool was enabled;
- ammunition template ID or displayed name;
- weapon, barrel, target, armor, material, layers, and spacing when relevant;
- expected and actual behavior;
- numbered reproduction steps and frequency;
- relevant configuration and the smallest useful log excerpt;
- a telemetry report, screenshot, or video when it materially helps.

Never upload a full game directory, EFT DLL, EFT asset, profile, credential, or private key. Review logs, reports, screenshots, and videos for personal information before attaching them.
